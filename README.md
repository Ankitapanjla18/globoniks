# globoniks.com

Marketing site for Globoniks — a family-run software studio in Mohali,
Punjab. Next.js 14 (App Router), TypeScript, Tailwind CSS.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
```

## Build & run

```bash
npm run build
npm start
```

Every route is statically prerendered. `/sitemap.xml` and `/robots.txt`
are generated by `src/app/sitemap.ts` and `src/app/robots.ts`.

## Where things live

| What | Where |
|---|---|
| Business facts (address, GSTIN, phone, schema) | `src/lib/site.ts` |
| Portfolio | `src/data/projects.ts` |
| Services + roadmap | `src/data/services.ts` |
| Mentorship tracks | `src/data/mentorship.ts` |
| Live-site screenshots | `public/screenshots/` |
| Social share card | `public/og-card.png` (regenerate: `python scripts/generate-og-card.py`) |

Content rule for all data files: **unknown facts are omitted, never
guessed.** Anything requiring owner input is tracked in `NEEDS-INPUT.md`;
every change is recorded in `CHANGELOG.md`.
